Rules: never push directly to `main`; never force-push/reset/delete branches without approval; preserve Web Forms IDs, `runat="server"`, validators, event handlers, postbacks, master pages and binding; never invent page counts, schema, features or test results; never commit secrets. These docs define standards, not proof that every recommendation is already implemented.
